# AI-Assisted Development Workflow

## AI Prompts Used

### Prompt 1 — Project Planning
I asked AI to plan a React movie application with a home page, favourites page, search functionality, movie cards, responsive design, and localStorage persistence.

### Prompt 2 — Application Development
I asked AI to build the movie application using React with a mock movie dataset, search, favourites, poster fallbacks, loading/empty states, and responsive styling.

### Prompt 3 — Testing
I asked AI to help test the application's search, favourites, persistence, empty states, and responsive behaviour.

## How AI Assisted

AI was used as a development assistant throughout the project. It helped with application structure, React component ideas, state management, mock movie data, styling, and debugging.

I reviewed the generated implementation and tested the application manually in the browser.

## Manual Improvements and Corrections

After reviewing the AI-generated implementation, I manually checked and improved the application.

Examples include:

- Checked the application in the browser and corrected issues when they appeared.
- Tested the search functionality with different movie names.
- Tested adding and removing favourites.
- Verified that favourites remained after refreshing the page.
- Checked the empty search-result state.
- Checked the responsive layout on a smaller screen.
- Reviewed the generated code and kept the implementation simple and understandable.

## Testing

The application was tested for:

- Initial movie grid rendering
- Search functionality
- Empty search results
- Adding favourites
- Removing favourites
- Favourites navigation
- Favourite persistence using localStorage
- Poster fallback behaviour
- Responsive layout
