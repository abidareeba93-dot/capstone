# Claude Code Instructions

## Project
This is my capstone project.

## Development Conventions
- Keep the code simple and readable.
- Use clear and meaningful names.
- Explain important changes.
- Do not add unnecessary dependencies.
- Test changes before considering a task complete.

## Git Conventions
Use Conventional Commits for all commits.

Examples:
- feat: add new feature
- fix: fix a bug
- docs: update documentation
- chore: update project setup

## AI Assistance
Claude Code may be used to help develop, review, and improve this project.
## Workflow

- Review changes before committing.
- Keep commits focused on one change.
- Use Conventional Commits.
## Project-Specific Rules

- All form inputs must use controlled React state and show validation errors only after the field is touched or the form is submitted.
- Every form input must have a properly associated label, and interactive controls such as the notifications switch must include appropriate accessible attributes.
- Every new form feature must include tests for valid submission, required-field errors, invalid input, and relevant edge cases before the feature is considered complete.
